How to use
  1. Add one dial per coloured dial in the puzzle, then use − / + under a dial to match its shape — a square dial has 4 positions, a hexagon has 6.
  2. Drag the pointer — or focus the dial and use the arrow keys — to the position the dial starts in. A dial lights up once its pointer is aimed at the hub, which is the solved position.
  3. Every button gets one slot per dial: set how many times it turns that dial. If a button shows two blue icons in game, its blue slot is 2.
